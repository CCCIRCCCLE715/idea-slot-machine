# 灵感老虎机

一个红金色复古老虎机网页。左侧随机抽取网络热梗，右侧随机抽取创作形式，组合成下一次可以尝试的创作题目。

## 功能

- 双滚轮独立运行，支持随机结果和指定结果。
- 点击“开始”后滚动，再次点击可以提前进入减速阶段。
- 停靠前有渐进减速、前冲、回退和机械回弹。
- 中奖后触发双跑马灯追逐效果。
- 适配桌面和手机屏幕，页面始终保持在一屏内。
- 使用浏览器本地存储保存自定义词库。

## 本地运行

这个项目不需要安装依赖。进入项目目录后启动一个静态文件服务器：

```bash
python3 -m http.server 3000
```

浏览器打开：

```text
http://localhost:3000
```

直接打开 `index.html` 也可以浏览页面，但建议使用静态服务器，以免浏览器限制部分功能。

## 修改词库

默认词库位于 `app.js` 文件顶部的 `defaults` 对象中：

```js
const defaults = {
  memes: ['我的刀盾', '闪身步'],
  formats: ['PPT', '个人网站']
};
```

每组至少保留四个不同选项。同一选项再次出现前，滚轮会确保中间隔开至少三个其他选项。

当前页面载入后的前两次结果经过预设：

1. 我的刀盾 + 个人网站
2. 闪身步 + 个人网站

第三次开始恢复随机抽取。
